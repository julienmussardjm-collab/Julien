# Mini Site Mignon 💕

Un mini site interactif avec protection par mot de passe.

## 🌐 Accès au Site

### Option 1: GitHub Pages (Recommandé)
Pour activer GitHub Pages et rendre le site accessible publiquement:

1. Allez dans **Settings** (Paramètres) du dépôt
2. Cliquez sur **Pages** dans le menu de gauche
3. Sous "Source", sélectionnez:
   - **Branch**: `copilot/create-mini-site-html`
   - **Folder**: `/ (root)`
4. Cliquez sur **Save**

Après quelques minutes, votre site sera disponible à:
**https://julienmussardjm-collab.github.io/Julien/**

### Option 2: Voir le code directement
Vous pouvez voir le code source sur GitHub:
https://github.com/julienmussardjm-collab/Julien/blob/copilot/create-mini-site-html/index.html

Et le télécharger pour l'ouvrir localement.
